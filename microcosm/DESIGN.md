# 《画境坍缩：千界之眸》设计文档 v2（已实现版）

> 本文是对 `Idea/ai.md`（v1）的评审与调校，并记录实际落地的版本。
> 在线游玩：https://ffvoid.com/microcosm/　·　代码：`ffvoid` 仓库 `microcosm/` 目录（纯静态，three.js r160，无构建步骤）

---

## 一、对 v1 的评价

**保留并强化的亮点**
- 核心意象非常好：失明画师 → 未点睛的肖像 → 瞳孔里嵌套六个世界 → 尽头回到画室本身（莫比乌斯闭环）。“点睛”这个动作天然就是结局。
- “六界六画风”是视觉卖点，同时解决了长流程的审美疲劳。
- “手里的东西不随世界伸缩”是一个真正好玩的、能撑起整款游戏的规则。

**需要调整的问题**

| v1 问题 | 调整 |
|---|---|
| 目标 Quest 3 / PCVR，用户实际是 **Quest 2** | 全部按 Quest 2 72Hz 预算设计：无后期处理、静态几何按材质合并（每界 20~40 个 draw call）、单 pass 风格着色器、固定注视点渲染 |
| 第一幕“放大提灯内部”是另一条缩放轴，和“只能沿传送门链缩放”的引擎模型冲突 | 改为：**她眼角的一点余温**太小捏不住 → 用透镜放大时握住它 → 缩回来它就变成了一团能点灯的火。一步教会核心规则 |
| 第二幕几乎没有玩法；第五幕要的“核心棱镜”从未设计 | 第一界改为整条连锁的终点（灯笼太阳解冻睡莲 → 星盘桥合拢 → 发条鸟衔来**发条钥匙**），钥匙要带到第三界唤醒巨鲸，形成跨三层的因果链 |
| 视错觉缝合要求 s=45、视角误差 < 0.08 rad，VR 里极易挫败 | 改为“补全一个巨大的包豪斯圆环”：第五界里的炭笔拱是由程序**逆投影**算出来的，在设计缩放下与圆环缺口完全重合；判定放宽到 0.06 rad 并有实时发光反馈和两级提示 |
| 所有材质 `transparent: true` + UV 排线 | 改为不透明 + **物体空间坐标 + fwidth 抗锯齿**的图案：缩到很小时自动退化为平涂色块（这正是 v1 想要的“笔触化形”），放大时线条浮现，且不会出现 UV 拉伸 |
| 60 分钟时长与内容量不匹配 | 诚实地定为 **25~40 分钟**，每界一个清晰的谜题 + 一个跨界动作 |
| “老画师背影”“少女自画像”与人物剪影偏好冲突 | 画师以“缺席”表现：空凳子、搭着的外套、悬在半空的笔；肖像做成莫迪利亚尼式的抽象脸，眼睛留白 |
| 用户可能不戴头显 | 同一套代码三种输入：电脑（鼠标键盘）、手机（触屏）、Quest（WebXR） |

## 二、核心规则（玩家视角）

1. **世界会伸缩，你的手不会。** 握在手里的东西保持它被握住那一刻的物理大小。
2. 放大时握住 → 缩回来它就变大；缩小时握住 → 放大回去它就变小。
3. 把东西松手放进“气泡”（下一层世界）里，它就留在那个世界。
4. 传送门未开启时，透镜只能放大约 17 倍（放大镜模式），不能穿越。

## 三、引擎：环形尺度原点重置

- 连续缩放量 `z`：层级 `L = floor(z)`，进度 `f = z − L`，相邻层级比例 `K = 900`，每个世界穹顶半径 30 m（嵌在上一层时是一颗 3.3 cm 的“眼珠 / 花粉 / 露珠 / 珍珠”）。
- 当前世界以 `S = K^f` 绕固定点 `Q = (K·p − A)/(K−1)` 缩放；子世界以 `S/K` 嵌在传送门 `p` 处。`A` 是抵达锚点（开始缩放时头部位置；从内层退回时为穹顶中心）。
- `f → 1` 时子世界恰好成为单位变换（只剩平移 `A−E`），越界那一帧把平移交给玩家 rig，**画面零跳变**。GPU 坐标始终在 `[1/K, K]` 内，不会抖动。
- 进入气泡后父世界停止渲染，改渲染孙世界，保证抵达时传送门里已有内容。
- 每个世界的雾以“气泡表面离相机最近点”为原点，所以从外面看气泡时，里面的世界依然清晰。
- 第 5 层的子世界就是第 0 层：`z` 到 6 时归一回 0，形成闭环。通关后解锁无限缩放。

## 五、美术基准：纪念碑谷 / 风之旅人 / 奥日

- **统一光照语言**：所有世界共用一套着色模型：干净的分面三色调（阴面、阳面、顶面）、冷暖分离（每界一对阴影 / 阳光色）、高度渐变（建筑越往下越融进雾里，纪念碑谷式“无底”的浮岛）、接地阴影、逆光边缘光、高度雾。六界的画风笔触（水粉、排线、纸纹、木刻、网点、炭笔）只作为克制的点缀叠在上面，不再满屏噪点。
- **纪念碑谷式建筑套件**（`mvkit.js`）：圆角体块、深紫拱窗、檐口、穹顶 / 尖塔 / 洋葱顶 / 城垛、层叠基座、阶梯、柔软云团。第一界整体用它重建。
- **光**：风之旅人式体积光束（沿长度渐隐、边缘柔和、缓慢流动），暖色悬挂纸灯，大日晕；电脑端加辉光（只让真正发光的东西溢光）与逐世界调色、暗角。
- **天空**：全部重画为平滑渐变 + 柔和云团 + 日月光晕，第一界的虹膜天空改为金—天青—珊瑚的柔和放射纤维。
- **小画伏笔**：画室墙上四幅小画分别预示虹膜、纸林、巨浪、包豪斯四个世界。
- 说明：本会话没有生图工具，所有资产均为程序化建模 + 着色器 + Canvas 绘制，因此体积小（除 three.js 外不到 200 KB）、加载快。

## 六、电脑版与 WebXR 版的差异

| | 电脑 | 手机 | Quest 2（WebXR） |
|---|---|---|---|
| 看 | 鼠标（指针锁定） | 右侧拖动 | 头部 |
| 走 | WASD / 方向键 | 左下虚拟摇杆 | 左摇杆平滑移动；右摇杆左右 30° 快速转身 |
| 握 / 触碰 | 单击或 E，准星射线 3.6 m | 轻点 / “握住”按钮 | 扳机：手边 7 cm 内直接握住，否则射线 4.5 m 吸取 |
| 缩放 | 滚轮（带惯性）、Z/X，Shift 精细 | 双指捏合、＋／－ 按钮 | **双手侧握拉开 / 合拢**（对数映射），或右摇杆上下 |
| 字幕 | 屏幕底部 DOM | 同左 | 跟随头部的画布面板（懒跟随，不贴脸） |
| 进度 | 左上角颜料点 | 同左 | 左手腕上的六色调色盘 |
| 防眩晕 | 轻微暗角 | 同左 | 缩放速度驱动的水彩毛边遮罩 + 穿越气泡时的水彩擦除 |

## 七、性能预算（Quest 2）

- 静态装饰全部经 `Decor` 按材质合并；描边壳也合并成每界一个网格。
- 同一时刻最多渲染两层世界（当前 + 子，或子 + 孙）。
- 无实时灯光、无阴影、无后期；“光束 / 光晕”用加色网格。
- `setFoveation(0.6)`，像素比上限 1.75。

## 八、文件结构

```
microcosm/
├── index.html            标题、菜单、HUD、字幕（DOM）
├── vendor/               three.module.js r160、BufferGeometryUtils
└── js/
    ├── main.js           渲染器、三种输入、主循环、菜单、存档恢复
    ├── engine.js         无限缩放引擎（尺度原点重置、气泡判定、雾原点、水彩擦除）
    ├── styles.js         六界风格着色器、天空、描边壳、玻璃、光晕、微粒
    ├── geo.js            程序化几何与按材质合并
    ├── world.js          世界基类
    ├── interact.js       跨尺度抓取 / 触碰
    ├── story.js          旗标、台词队列、分级提示、颜料、存档
    ├── text.js           全部中英文台词
    ├── ui.js / audio.js  界面 / 程序化声音（六界音色 + 贯穿全剧的动机）
    ├── mvkit.js          纪念碑谷式建筑套件
    ├── post.js           电脑端辉光 + 调色
    ├── atelier.js        第 0 / 5 界共用的画室布局
    ├── portrait.js       程序化绘制的《凝视》（水粉 / 炭笔 / 点睛）
    ├── stitch.js         视错觉缝合的逆投影
    ├── finale.js         终幕
    └── worlds/w0~w5.js   六个世界
```

调试：地址加 `?debug`，游戏中按数字键 0~5 直接跳到对应世界。
